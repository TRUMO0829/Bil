# Билгүүндарьд ♡

“Танилцсандаа таатай байна” — Билгүүндарьд зориулсан зураг, захидал бүхий хувийн вэбсайт.

## Агуулга

- Утас, компьютерийн дэлгэцэд тохирох зөөлөн ягаан загвар.
- Таван зурагтай цомог; томруулах, сум болон шудралтаар зураг солих.
- Дарж нээдэг захидал, жижигхэн мэндчилгээнүүд.
- Гарын удирдлага, хөдөлгөөн багасгах төхөөрөмжийн тохиргооны дэмжлэг.

## Локал үзэх

`index.html` файлыг браузераар нээнэ. Эсвэл репозиторийн фолдерт:

```sh
python3 -m http.server 3000 --bind 127.0.0.1
```

Дараа нь `http://localhost:3000` хаягаар үзнэ.

## Файлууд

- `index.html`: үндсэн хуудас, захидал.
- `styles.css`: загвар, дэлгэцийн хэмжээнд тохируулах дүрэм.
- `script.js`: цомог, захидал, жижигхэн мэндчилгээнүүд.
- `assets/`: таван зураг болон favicon.
- `vercel.json`: нэмэлт build/install шаарддаггүй статик сайтын тохиргоо.

## Vercel

Репозиторийн үндсэн фолдероос нийтэлнэ. Framework нь **Other**, Output Directory нь **.**. `vercel.json` дээр эдгээр тохиргоог тодорхойлсон. `main` салбарын өөрчлөлт холбогдсон Vercel төслийн шинэ нийтлэлтийг эхлүүлнэ.
