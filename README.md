# Борлуулалтын үнийн саналын процессын шинжилгээ

Өрсөлдөгчийн үнийн судалгаа, тээврийн зардлын санал, борлуулах үнийн тооцооллыг нэг урсгалд холбох тайлан.

[Тайланг татах (Word)](Борлуулалтын%20үнийн%20санал%20гаргах%20процессын%20шинжилгээний%20тайлан.docx)

Тайланд процессын зураглал, мэдээллийн урсгал, эрсдэлийн хяналт, автоматжуулалт, ERP-ийн холболт болон жишиг хүн цагийн тооцоог багтаав. Хүн цаг болон зардлын тооцоонууд бодит хэмжилтээр баталгаажаагүй жишиг таамаглал болно.
